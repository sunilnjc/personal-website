## Notes from the work

- **Separate guidance from diagnostics.** A camera operator needs one clear cue; detailed evidence belongs in the report.
- **Keep a replayable history.** An immutable journal lets a ledger rebuild its projections and distinguish when an event happened from when it became known.
- **Make missing data visible.** Sensor and market-data tools should show unavailable or uncertain results explicitly.
